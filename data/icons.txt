# Icons, and their colors, for directories, file names and extensions: the
# source of truth for our eza and nvim icons. See icons.py and build-icons.py.
#
# "color NAME HEX" lines define the colors, and "default KIND ICON COLOR" lines
# the icons for files with an extension nothing knows (KIND file), files with no
# extension (noext) and directories (dir). These match eza's built-in defaults,
# since its theme can't change them. The others are "KIND NAME ICON COLOR",
# where KIND is dir, file, ext or filetype (an nvim filetype, which otherwise
# gets the icon of an extension with that filetype), ICON is a Nerd Font glyph
# name (e.g. oct-gear) or codepoint (e.g. U+F423), and COLOR is one of the
# colors. Names can't contain whitespace, and lines starting with # are
# comments.
